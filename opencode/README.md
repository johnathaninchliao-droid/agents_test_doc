# OpenCode 專屬工作區

此目錄為專門分配給 **OpenCode CLI** 操作與練習的獨立工作區。

---

## 目錄定位與一對一分配

- **對應代理**：OpenCode (`opencode`)
- **工作路徑**：`C:\Users\User\Documents\多重代理\opencode`
- **對應 Herdr Space**：`多重代理(opencode)`

---

## 包含檔案清單

1. [AGENT_COMMANDS.md](./AGENT_COMMANDS.md) - OpenCode CLI 專屬指令說明手冊（CLI、斜線指令、快捷鍵）
2. [專案與專案等級.md](./專案與專案等級.md) - 「專案」與「專案等級」說明，含設定層級與範例
3. [exception_handling.md](./exception_handling.md) - 例外處理（Exception Handling）學習檔案
4. [分支練習.ipnb](./分支練習.ipnb) - Git 分支操作演練檔案

---

## 快速啟動

在 PowerShell 終端機中切換至此目錄並啟動 OpenCode：

```powershell
cd C:\Users\User\Documents\多重代理\opencode
opencode .
```
