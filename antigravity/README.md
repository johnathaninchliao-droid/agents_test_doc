# Antigravity 專屬工作區

此目錄為專門分配給 **Antigravity CLI (agy)** 操作與練習的獨立工作區。

---

## 目錄定位與一對一分配

- **對應代理**：Antigravity (`agy`)
- **工作路徑**：`C:\Users\User\Documents\多重代理\antigravity`
- **對應 Herdr Space**：`多重代理(antigravity)`

---

## 包含檔案清單

1. [AGENT_COMMANDS.md](file:///C:/Users/User/Documents/多重代理/antigravity/AGENT_COMMANDS.md) - Antigravity CLI 專屬指令說明手冊
2. [exception_handling.md](file:///C:/Users/User/Documents/多重代理/antigravity/exception_handling.md) - 例外處理（Exception Handling）學習檔案
3. [分支練習.ipnb](file:///C:/Users/User/Documents/多重代理/antigravity/分支練習.ipnb) - Git 分支操作演練檔案

---

## 快速啟動

在 PowerShell 終端機中切換至此目錄並啟動 Antigravity：

```powershell
cd C:\Users\User\Documents\多重代理\antigravity
agy
```
